# Print names of annotations in a ldscore fileset

Print names of annotations in a ldscore fileset

## Usage

``` r
get_annot_names(ldscore_dir)
```

## Arguments

- ldscore_dir:

  A filepath to a ldscore directory

## Value

a character vector of column names

## Examples

``` r
if (FALSE) { # \dontrun{
get_annot_names("ldscore/dir/celltypes")
} # }
```
